# Política de privacidad / Privacy Policy

*Última actualización / Last updated: 2026-09-28*

## Español

**bayesian-compose** es un skill que se ejecuta íntegramente dentro del asistente de IA que lo carga (Claude, Perplexity, Mistral u otro). El autor no opera ningún servidor ni servicio asociado a este plugin.

- **Qué lee:** los borradores y la información que tú escribes en la conversación para componer un mensaje. Pueden incluir nombres o direcciones de email del destinatario.
- **Qué envía fuera:** nada. El plugin no incluye servidores MCP, conectores ni llamadas a servicios externos. El autor no recibe ningún dato.
- **Qué guarda:** nada por defecto. La telemetría opcional solo se activa si creas a mano la carpeta `~/.bayesian-compose/` en tu propio equipo. En ese caso se guardan únicamente metadatos (puntuaciones, tipo de mensaje, criterios, número de iteraciones), **nunca** el texto del mensaje ni datos identificativos del destinatario o de terceros. Puedes borrar esa carpeta en cualquier momento.
- **Plataforma:** el tratamiento de tus conversaciones se rige por la política de privacidad del asistente que uses (por ejemplo, la de Anthropic para Claude).
- **Menores:** el plugin no está dirigido a menores de 18 años.

## English

**bayesian-compose** is a skill that runs entirely inside the AI assistant that loads it (Claude, Perplexity, Mistral or other). The author operates no server or service associated with this plugin.

- **What it reads:** the drafts and information you type into the conversation to compose a message. These may include recipients' names or email addresses.
- **What it sends off-platform:** nothing. The plugin contains no MCP servers, connectors or calls to external services. The author receives no data.
- **What it stores:** nothing by default. Optional telemetry is enabled only if you manually create the `~/.bayesian-compose/` folder on your own machine. In that case only metadata is stored (scores, message type, criteria, iteration count), **never** the message text or identifying data about the recipient or third parties. You can delete that folder at any time.
- **Platform:** your conversations are governed by the privacy policy of the assistant you use (for example, Anthropic's for Claude).
- **Minors:** the plugin is not intended for users under 18.
